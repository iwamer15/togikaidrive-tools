# togikaidrive-tools

自動運転ミニカー(togikaidrive-dev)を、ターミナル操作にあまり慣れていない人でも扱えるようにするための、ブラウザで動くローカルツール一式。**config.pyの編集・走行データの前処理・学習の実行・ラズパイとのファイル同期・実機のモーター確認**を、1つの画面(ポータル)から行えます。

まずこのページの「[はじめての人はここから](#はじめての人はここから)」を読んでください。

## これは何でできているか

すべて**Pythonの標準ライブラリだけ**で動く小さなWebサーバーです(`pip install`は不要)。各ツールは単体でも起動できますが、`togikaidrive-portal`から1つの画面としてまとめて使うのがおすすめです。

ツールはすべて`lab/`の中にあります(`togikaidrive-dev/`は車本体のコードで、`lab/`の外・リポジトリ直下にあります)。

| ツール(`lab/`の中) | 役割 | 単体起動時のURL |
|---|---|---|
| `togikaidrive-portal` | 他の全ツールを1画面にまとめる入り口 | http://localhost:8898 |
| `togikaidrive-config-editor` | `config.py`(設定ファイル)の編集、ラズパイとの同期、モーター校正 | http://localhost:8899 |
| `data-preprocessing-tool` | 走行データ(catalogファイル)のグラフ表示・不要区間の削除 | http://localhost:8900 |
| `training-execution-tool` | 測距センサーモデル(nn)の学習実行・進捗表示 | http://localhost:8901 |
| `annotation-tool-launcher` | 画像アノテーションツール(別の大きなデスクトップアプリ)の起動ボタン | http://localhost:8902 |
| `image-learning-tool` | 画像学習(Google Colab)の導線・学習結果(MLflow)の分析 | http://localhost:8903 |
| `raspi-control-tool` | ラズパイへのツール配置・実機制御エディタの起動停止・モーター緊急停止 | http://localhost:8904 |
| `raspi-editor` | **ラズパイ上で動く**実機制御エディタの入口(普通は手動起動せず、上のraspi-control-toolから使う) | ラズパイの http://\<IP\>:8899 |

`shared/`は上記ツール共通の部品(SSH連携・画面デザイン)で、単体では起動しません。

### PC上の画面と実機制御の画面の見分け方

ポータルの設定エディタと、ラズパイ上の実機制御エディタは中身が同じなので画面がよく似ています。取り違えないよう次のように表示が違います。

- **紺のヘッダー + 灰色の帯「💻 このPC上の画面です」** → PC上の画面。モーターはモックで、**車は動きません**。
- **赤いヘッダー + 赤い帯「🍓 実機モード」** → ラズパイ上の実機制御エディタ。**操作は実際の車に届きます**。
- 黄色い帯「⚠️ モーターに接続できていません」 → 実機制御として起動したが実機に繋がっていない(車は動きません)。

## はじめての人はここから

### 1. 必要なもの

- **Python 3**(3.9以上を推奨)。Mac・Windowsどちらでも動きます。追加のインストールは不要です。
- ラズパイに**SSH鍵認証**で繋がる状態(パスワード認証は使えません)。
- ブラウザ(Chrome・Safari・Edgeなど)。

`python3 --version` をターミナル(Windowsは PowerShell)で実行して、バージョンが出ればOKです。

### 2. コードを入手する

GitHubから取得します。

```bash
git clone https://github.com/iwamer15/togikaidrive-tools.git
```

gitに慣れていない場合は、GitHubのページ右上の「Code」→「Download ZIP」で取得し、好きな場所に展開してください。

### 3. ラズパイへのSSH鍵認証を設定する(初回のみ)

まだ鍵を作っていない場合:

```bash
ssh-keygen -t ed25519
```

(すべてEnterでOK。パスフレーズは空でも可)

作った鍵をラズパイに登録します(`<ラズパイのIPまたはホスト名>`は例えば`togikai13.local`のようなもの):

```bash
ssh-copy-id pi@<ラズパイのIPまたはホスト名>
```

登録できたか確認します(パスワードを聞かれずに繋がればOK):

```bash
ssh pi@<ラズパイのIPまたはホスト名> echo OK
```

### 4. ポータルを起動する

**リポジトリ直下にある起動スクリプトをダブルクリックするだけで起動できます。**

- Mac: `ポータルを起動.command`
- Windows: `ポータルを起動.bat`

少し待つとブラウザで自動的に **http://localhost:8898** が開きます。終了するには、開いたターミナル(黒い画面)を閉じるか、その中でCtrl+Cを押してください。

(ターミナルで手動起動したい場合は以下でも同じです)

```bash
cd togikaidrive-tools/lab/togikaidrive-portal
python3 server.py
```

### 5. ラズパイへの接続設定をする(初回のみ)

ポータルの「🔧 設定エディタ」タブ → 「🔌 ラズパイ連携」を開き、以下を入力して「接続設定を保存」→「接続テスト」を押します。

| 項目 | 入力例 |
|---|---|
| ホスト名 / IP | `togikai13.local` または `192.168.1.23` |
| ユーザー名 | `pi` |
| ポート | `22` |
| SSH秘密鍵パス | 空欄でOK(手順3で`~/.ssh`に作った既定の鍵を使う) |
| ラズパイ上のtogikaidrive-devのパス | `/home/pi/togikaidrive-dev` |

「接続OK」と出れば成功です。この設定は自分のPC内だけに保存され(`lab/shared/ssh_connection.json`)、他のメンバーとは共有されません。**メンバーそれぞれが自分のPCでこの手順を行う必要があります。**

### 6. 実機(モーター)を確認する

ポータルの**モーターは常にモック(シミュレーション)**です。実際にモーターを動かすには「🍓 ラズパイ実機」タブから、ラズパイ側でツールを起動します。

1. 「ツールを配置 / 更新」(初回・更新時のみ)
2. 「起動」→ 「起動中(利用可)」になるまで待つ
3. 「開く ↗」→ 開いたページの「⚙️ 操作」タブ →「🔧 モーター校正」

**必ず車体を持ち上げ、タイヤが床から浮いた状態で試してください。** スロットルは±0.10〜0.15程度の低速から、0.05刻みで確認します。ジジっとノイズが鳴り続けたら「■ 停止」を押してください。ネットワーク経由の停止はあくまで補助なので、電源やジョイスティックですぐ物理的に止められる状態を保ってください。

終わったら「🍓 ラズパイ実機」タブの「停止」を押します。

## よくある詰まりポイント

実際に作業中に遭遇したものです。同じ症状が出たら、まずここを確認してください。

**Mac: 「"ポータルを起動.command"は開発元を確認できないため開けません」と出る**
GitHubからダウンロードしたファイルにmacOSが警告を出しています。ファイルを右クリック(またはControl+クリック)→「開く」を選び、出てきたダイアログでもう一度「開く」を押してください。一度これをすれば次回からは警告なしで開けます。

**Windows: 「WindowsによってPCが保護されました」と出る**
「詳細情報」→「実行」を押してください。

**Chromeで「このサイトにアクセスできません / ERR_ADDRESS_UNREACHABLE」と出る**
macOSの「ローカルネットワーク」アクセスをChromeに許可していないことが原因です。「システム設定 → プライバシーとセキュリティ → ローカルネットワーク」でGoogle Chromeをオンにし、Chromeを再起動してください。急ぎの場合はSafariで開くか、ホスト名の代わりにIPアドレス(例: `192.168.1.23:8899`)を使ってください。

**`python3 server.py` が「ファイルが見つかりません」等で起動しない**
それぞれのツールは、そのツール自身のフォルダの中で実行する前提です(`cd lab/togikaidrive-portal && python3 server.py` のように、必ずそのフォルダに移動してから実行してください)。

**ラズパイでnanoでconfig.pyを開いたのに中身が空**
ホームディレクトリ(`~`)で`nano config.py`を実行すると、そこには無いので新規の空ファイルとして開かれます。`cd togikaidrive-dev && nano config.py`のように移動してから開いてください。

**nanoが「File is being edited by pi ... open anyway?」と聞いてくる**
前回のセッションの消し忘れロックです。別ターミナルで`ps -p <PID>`を実行して何も出なければ古いロックなので、`Y`で開いて問題ありません。気になる場合は編集後に`rm ~/togikaidrive-dev/.config.py.swp`で消しておきます。

**「🍓 ラズパイ実機」で起動してもなかなか使えるようにならない**
判断ロジック・YOLO関連の重いライブラリ(torch等)を読み込まない軽量モードで起動しているので、通常は数秒で立ち上がります。それでも長い場合は「状態を更新」でログを確認してください。

**モーター校正のスライダーを動かしても何も起きない**
「⚪ モック」のままなら、ポータル(Mac/Windows側、http://localhost:8898)を操作しています。実機に繋げるには「🍓 ラズパイ実機」タブの「開く ↗」から開いたページ(バッジが「🟢 実機接続中」)を使ってください。

このリポジトリ(`ト技会-minicar`)の管理者に連絡してください。実機に関する不具合(配線・ESCの極性など)は、ラズパイの貸出元にも確認が必要な場合があります。
