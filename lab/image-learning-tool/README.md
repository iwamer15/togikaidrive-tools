# 画像学習パネル

画像ベースのモデル学習(YOLO・走行モデル等)の実行導線と、学習結果の分析を行うローカルツール。

## 背景

画像ベースの学習はGPUが要るため、ローカル(Mac/ラズパイ)ではなくGoogle Colabで実行する運用になっている。データセットのGoogle Driveへの転送・Colabノートブックの生成・学習後のモデル/実験記録(MLflowの`mlruns/`)のダウンロード・マージは、既存のアノテーションツール(`togikaidrive-dev/annotation_training_d2j/main.py`のCloudメニュー、`_transfer_to_colab`等)に**既に実装済み**のため、このツールでは再実装しない。

このツールの役割は2つだけ:
1. アノテーションツールを起動するボタン(実際の転送操作はそのアプリ内で行う)
2. アノテーションツールがローカルにマージ済みの`mlruns/`を読んで、学習曲線・パラメータを表示する「学習分析」

## 使い方

```bash
cd ト技会-minicar/lab/image-learning-tool
python3 server.py
```

ブラウザで `http://localhost:8903` を開く。

## 画面構成

1. **Colabで学習する** — アノテーションツールを起動するボタンと、Cloudメニューでの操作手順の案内
2. **学習分析** — `annotation_training_d2j/mlruns/`を直接パースして(`mlflow`パッケージ不使用)、実験/run選択→パラメータ表・学習曲線(train/val loss等)を表示

## 制約・今後の拡張候補

- `mlflow`パッケージには依存しない(ファイル形式を直接読むだけ)。MLflowの保存形式が将来変わった場合は追従が必要。
- PCA等の高度なデータ分析は現時点では含まない。必要になれば別パネルとして追加を検討する。
- YOLO学習の完全な自動化(ヘッドレス実行)はスコープ外。Colab上での手動実行を前提にしている。
