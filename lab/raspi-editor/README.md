# ラズパイ実機制御エディタ

ラズパイ上で動かす、実機(モーター・サーボ)に触れる専用の設定エディタの入口。ポータルの「🍓 ラズパイ実機」タブ(`raspi-control-tool`)から、配置・起動・停止・「開く ↗」で使う。

## なぜ別フォルダか

ポータルの設定エディタと、ラズパイ上で動く実機制御エディタは、中身が同じ`togikaidrive-config-editor`のため画面がほぼ同じになる。取り違えると「モックのつもりで実機を動かす」「実機のつもりで操作したらモックだった」が起きるので、**実機制御として起動する入口を専用フォルダに分け、画面も見分けがつくようにしている**。

コードの複製はしない。このフォルダの`server.py`は設定エディタを読み込み、`UI_MODE = "raspi"`を設定して起動するだけ。

## 画面の見分け方

| 画面 | ヘッダー | 帯 |
|---|---|---|
| ポータル内の設定エディタ(PC上) | 紺 | 灰色「💻 このPC上の画面です — モーターはモック」 |
| 実機制御エディタ(実機に接続中) | **赤** | **赤「🍓 実機モード — 実際の車に届きます」** |
| 実機制御エディタ(実機に未接続) | 黄土色 | 黄色「⚠️ モーターに接続できていません(モック動作)」 |

実機のモーターに繋がっている間は、どこから起動しても(この入口以外でも)赤で表示される。判定は`HARDWARE_AVAILABLE`(実際にPCA9685を初期化できたか)で行うため、「実機のつもりで起動したが繋がっていなかった」場合も黄色の警告で分かる。

## 手動で起動する場合(ラズパイ上)

```bash
cd ~/lab/raspi-editor
~/togikaidrive-dev/venv/bin/python3 server.py --no-ml
```

`http://<ラズパイのIP>:8899` を開く。`--no-ml`はtorch等の重い読み込みを省く軽量起動。
