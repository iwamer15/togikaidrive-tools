# togikaidrive 設定エディタ

`togikaidrive-dev/config.py` のうち、**機械学習チュートリアルで触ることが多い項目だけ**を、ブラウザのフォームから安全に編集するためのローカルツール。

## 背景

`config.py` は473個もの設定項目が並ぶ71KBの生Pythonファイルで、目的の行を手作業で探して書き換えるのは大変(実際に直接編集してみて、書き換え箇所を探すだけで一苦労だったとのフィードバックあり)。また、`monitor.py`のブラウザ設定変更機能は実行中のメモリ上にしか反映されず、`train_pytorch.py`のような別プロセスの学習には影響しない。

このツールは、`config.py`ファイル自体を直接(該当行だけ)安全に書き換えることで、この2つの課題を解決する。

## 使い方

```bash
cd tools/togikaidrive-config-editor
python3 server.py
```

ブラウザで `http://localhost:8899` を開く(表示されるURLの通り、同じネットワーク内の別PC/スマホからもアクセス可)。

3つのカテゴリに分かれたフォームで値を確認・変更し、「変更を保存」を押すと `togikaidrive-dev/config.py` に書き込まれる。

| カテゴリ | 内容 |
|---|---|
| 📡 データ収集 | 走行モード(PLAN)・使用センサー(ACTIVE_SENSORS)・データ収集時の速度 |
| 🧠 学習パラメータ | エポック数・バッチサイズ・隠れ層の大きさ/数(train_pytorch.py用) |
| 🤖 モデル指定 | 学習済みモデルの保存先・ファイル名 |

## 安全性

- **標準ライブラリのみ**で動作(pip install不要。Raspberry Pi / Jetsonでもそのまま動く)
- 保存のたびに `config.py.bak.<日時>` という名前で自動バックアップを作成してから書き込む
- `config.py`全体を作り直すのではなく、**変更対象の行だけ**を正規表現で置き換える(他の470項目やコメントには触れない)
- 万が一おかしくなったら、直前のバックアップファイルを `config.py` にコピーし直せば元に戻る

```bash
# 元に戻す例
cp config.py.bak.20260825_153000 ../../togikaidrive-dev/config.py
```

## 項目を追加したい場合

`server.py` 冒頭の `FIELDS` リストにエントリを追加すれば、対応するフォーム項目が自動で増える(`kind`は `str` / `int` / `float` / `select` / `sensors` に対応)。
