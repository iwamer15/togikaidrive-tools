# togikaidrive 設定エディタ

`togikaidrive-dev/config.py`(480項目・1281行の生Pythonファイル)を、**ミニカーの処理カテゴリ別のパネルUI**からブラウザで安全に編集するためのローカルツール。

## 背景

`config.py` は目的の行を手作業で探して書き換えるのが大変(実際に直接編集してみて、書き換え箇所を探すだけで一苦労だったとのフィードバックあり)。また、`monitor.py`のブラウザ設定変更機能は実行中のメモリ上にしか反映されず、`train_pytorch.py`のような別プロセスの学習には影響しない。

このツールは、`config.py`ファイル自体を直接(該当行だけ)安全に書き換えることで、この2つの課題を解決する。

## 使い方

```bash
cd ト技会-minicar/togikaidrive-config-editor
python3 server.py
```

ブラウザで `http://localhost:8899` を開く(表示されるURLの通り、同じネットワーク内の別PC/スマホからもアクセス可)。

モーター校正ウィジェットで実機を動かしたい場合(ラズパイ上)は、システムの`python3`ではなく`Adafruit_PCA9685`が入っている`togikaidrive-dev/venv`のPythonで起動する。

```bash
cd ト技会-minicar/togikaidrive-config-editor
/home/pi/togikaidrive-dev/venv/bin/python3 server.py
```

## 画面構成(6カテゴリ)

config.py 自身が持つ33個のセクション見出しを実際に集計し、ミニカーの処理内容ごとに6分類したタブに整理している。

| カテゴリ | 内容 |
|---|---|
| 🔧 基本設定 | デバイス・Webモニター・記録形式など |
| 📡 認知 | 超音波・カメラ・LiDAR・IMU等のセンサー設定 |
| 🧭 自己位置推定 | SLAM / VSLAM / ArUco / AMCL（高度・任意機能） |
| 🧠 判断 | 走行モード(PLAN)・AIモデル・走行ロジック |
| ⚙️ 操作 | モーター校正・コントローラー設定 |
| 🔊 演出 | エンジン音など |

「⚙️ 操作」タブの先頭には、**実際にサーボ・ESCを動かしながらステアリング/スロットルのPWM値を校正できるウィジェット**が組み込まれている(旧`motor-calibration-panel`を統合したもの)。生のPWM値を送って試し、「これを中央にする」「これを前進最大にする」のようなボタンで確定すると、下にある`STEERING_CENTER_PWM`等の数値フィールドにその場で反映される。**確定した時点ではまだconfig.pyには書き込まれず**、他の設定と同じくページ下部の「変更を保存」を押して初めて書き込まれる(専用の保存ボタンは持たない。1つの保存フローに統一している)。

`motor.py`が使う`Adafruit_PCA9685`ライブラリと実I2Cバスが無い環境(開発機など)では、校正ウィジェットは自動的にモック(ログ出力のみ)にフォールバックする。ラズパイ上で実機を動かしながら校正するには、`togikaidrive-dev/venv`のPythonで起動する必要がある(後述)。

各タブは2層構成になっている。

1. **よく使う設定** — 手作業で選定し、説明文をつけたカード(現在37項目)。PLANを選ぶと、そのモードが何をするか・どのファイルが実装しているかの解説パネルとセンサー配置図が連動して表示される。
2. **詳細設定**（折りたたみ） — キュレーション対象外の残り約440項目を、config.py自身のセクション見出しから**その場で自動生成**する(ハードコードしていないので、config.pyの構造が変わっても追従する)。他の設定値を参照する計算式など、単純な値として安全に書き換えられない項目(16件)は読み取り専用で表示される。

**どちらの階層でも**、値を変更すると**入力・選択するたびその場で**「config.pyの何行目が」「変更前→変更後どうなるか」が確認できる(差分プレビュー)。変更した項目はカード/行全体がオレンジ色でハイライトされ、保存バーに「変更: N件」と表示されるので、複数タブにまたがって変更しても見失わない。

## 📄 コードタブ

「詳細設定」がkey=valueを抽出した表なのに対し、こちらはconfig.pyの**実コードをそのまま**カテゴリ別に表示する読み取り専用ビュー。コメント・空行を含む元の記述をそのまま確認できる。

## 🔄 再読み込み / 📋 テンプレート

- **再読み込み**: 起動時にconfig.pyの内容をキャッシュしており、通常のページ表示は高速なキャッシュから返す。ヘッダーの「🔄 再読み込み」を押すと、config.pyの内容が(SSH等で直接編集されて)変わっていないかハッシュで確認し、変わっていれば再生成・変わっていなければキャッシュ利用のままである旨をトーストで表示する。
- **テンプレート**: 現在のconfig.pyを任意の名前で保存しておき、後から一覧・適用・削除できる(`templates/<名前>.py` に保存)。「予選用」「決勝用」のように状況ごとの設定一式を切り替えたいときに使う。適用時も通常の保存と同じくバックアップを作成してから上書きする。

## 安全性

- **標準ライブラリのみ**で動作(pip install不要。Raspberry Pi / Jetsonでもそのまま動く)
- 保存やテンプレート適用のたびに `config.py.bak.<日時>` という名前で自動バックアップを作成してから書き込む
- `config.py`全体を作り直すのではなく、**実際に値が変わった行だけ**を書き換える(触っていない項目・コメント・空白は一切変化しない)
- 保存前にPythonの値として解釈できるか検証し、壊れた入力は書き込まれない
- 万が一おかしくなったら、直前のバックアップファイルを `config.py` にコピーし直せば元に戻る

```bash
# 元に戻す例
cp config.py.bak.20260825_153000 ../togikaidrive-dev/config.py
```

## 項目を追加・分類を変更したい場合

- 「よく使う設定」を増やす: `server.py` 冒頭の `CURATED_FIELDS` にエントリを追加する(`kind`は `str` / `int` / `float` / `bool` / `choice` / `select` / `sensors` に対応)
- カテゴリ分類を変える: `SECTION_CATEGORY`(config.pyのセクション見出し文字列 → カテゴリID)を編集する
