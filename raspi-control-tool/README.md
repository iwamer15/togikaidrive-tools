# ラズパイ実機パネル

ラズパイ上の設定エディタ(モーター校正ウィジェットなど、実機のPCA9685に触れる機能)を、ターミナル操作なしで「配置 → 起動 → 開く → 停止」できるようにするローカルツール。

## 背景

Mac/Windows上で動かしているポータルのモーターは「モック」で、実機には何も出力しない。車を実際に動かす確認は、**ラズパイ上で設定エディタを動かす**必要がある。ラズパイのターミナルで毎回起動するのは慣れていないメンバーには難しいため、`shared/ssh_connection.json`に保存済みのSSH接続設定を使い、ブラウザのボタンだけで済ませる。

## 使い方

ポータルの「🍓 ラズパイ実機」タブ、または単体で:

```bash
cd ト技会-minicar/raspi-control-tool
python3 server.py
```

`http://localhost:8904` を開く。事前に「設定エディタ → 🔌 ラズパイ連携」でSSH接続設定(ホスト・ユーザー・togikaidrive-devのパス)を保存し、鍵認証でsshできる状態にしておく。

1. **ツールを配置 / 更新** — `shared/`と`togikaidrive-config-editor/`を、ラズパイの`togikaidrive-dev`と同じ階層(例: `/home/pi/`)へ送る
2. **起動** — ラズパイ上で軽量モード(`--no-ml`)で設定エディタを起動。数秒で「起動中(利用可)」になる
3. **開く** — `http://<ラズパイ>:8899`。「操作」タブ →「🔧 モーター校正」のバッジが「🟢 実機接続中」なら実機に届く
4. **停止** — 設定エディタを止める。止める前にモーターへ0を送り、終了時にも停止処理が走る
5. **🛑 モーターを止める** — 起動中の設定エディタにスロットル・ステアリング0を送る。届かない場合はプロセスごと停止する

## 仕組み・設計上の注意

- **rsync不要**: 配置はPython標準の`tarfile`で固めてsshの標準入力に流し、ラズパイ側の`tar -xf -`で展開する。Windowsでもsshだけで動く(`shared/remote_link.py`の`push_directories_tar`)。追加・更新のみで、ラズパイ側にしか無いファイルは消さない。`ssh_connection.json`(各PC固有)と`templates/`は送らない。
- **常駐プロセス管理**: 起動は`setsid nohup`でsshを切っても動き続ける。PIDは`/tmp/togikai-config-editor.pid`、ログは`/tmp/togikai-config-editor.log`。停止はSIGTERMを送り、6秒待っても終わらなければSIGKILL。PID再利用による誤停止を避けるため、cmdlineに`server.py`が含まれることを確認してから送る(`remote_daemon_start/status/stop`)。
- **停止時にモーターを0へ戻す**: PCA9685はプロセス終了後も最後のパルスを出し続けるため、設定エディタ側でSIGTERMを受けたらCtrl+Cと同じ経路で終了し、`motor_instance.cleanup()`を必ず実行する。
- **軽量起動(`--no-ml`)**: torch等の重いライブラリ(判断ロジック・YOLO)の読み込みを省く。モーター校正だけなら数秒で立ち上がる。
- **I2Cバスの自動判別**: 設定エディタは`run.py`と同じく`detect_device()`でI2Cバス番号を決めてからモーターを初期化する(config.pyの既定値`I2C_BUS=7`はJetson用のため)。
- 状態確認はボタンを押した時だけSSHで問い合わせる(ページを開くたびにSSH接続はしない)。

## 安全上の注意

実際にモーターが動く。最初はタイヤを床から浮かせ、低速(スロットル ±0.10〜0.15程度)から確認すること。ネットワーク経由の停止はあくまで補助で、電源・ジョイスティックで物理的に止められる状態で操作する。
